# Campus-Navigator

**Campus-Navigator: Your essential interactive guide for university life. Easily locate buildings, classrooms, and facilities on campus. Navigate with confidence, save time, and explore your academic environment with ease. Perfect for students and visitors.**

## 🚀 Features

*   **Interactive Map:** Visually explore the campus layout.
*   **Location Search:** Quickly find specific buildings, departments, or facilities.
*   **Route Guidance:** Get directions to your destination within the campus.
*   **Points of Interest:** Highlight key locations like libraries, cafeterias, and student services.
*   **Responsive Design:** Accessible on various devices (desktop, tablet, mobile).

## ⚙️ Installation

To set up Campus-Navigator locally, follow these steps:

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/your-username/Campus-Navigator.git
    cd Campus-Navigator
    ```

2.  **Set up a Python virtual environment (recommended):**
    ```bash
    python -m venv venv
    source venv/bin/activate  # On Windows: `venv\Scripts\activate`
    ```

3.  **Install dependencies:**
    ```bash
    pip install -r requirements.txt # Assuming a requirements.txt will be added later
    ```

## ▶️ Usage

11.  **Run the application:**
    ```bash
    python app.py
    ```

12. **Access in your browser:**
    Open your web browser and go to `http://127.0.0.0:5000` (or the address shown in your console).
